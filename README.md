# 🎵 Musify - Simple Music Player Web App

Musify is a lightweight, responsive music player web app built using **HTML, CSS, and vanilla JavaScript**. It allows users to play, pause, and navigate between songs with a sleek and minimal UI — no libraries or frameworks used.

## 🚀 Features

- ▶️ Play / Pause music
- ⏭️ Next / Previous track
- 🎧 Auto play next song when current one ends
- 🔁 Seamless loop and reset support
- 📊 Real-time progress bar sync with audio
- 🎵 Dynamic update of song title and cover image
- 📱 Responsive design for mobile and desktop

## 🛠️ Tech Stack

- **HTML5** – Structure & Layout
- **CSS3** – Styling and Responsive Design
- **JavaScript** – Functionality & Interactivity
